Salesperson Filter in Accounting Report

Easily analyze accounting data by individual sales representatives

This module adds a Salesperson filter to Odoo’s built-in accounting reports, making it easier to analyze financial performance by each salesperson.

Compatibility

  • Tested with Odoo 18.0
Odoo.sh On Premise Odoo Online Odoo Community

Reports with Salesperson Filter

  • Partner Ledger
  • Balance Sheet
  • Aged Reports
  • General Ledger
  • Trial Balance
