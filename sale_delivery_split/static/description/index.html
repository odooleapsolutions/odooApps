SalesOrder Delivery Split

Allows splitting delivery orders in Sales Orders by enabling 'Split Delivery' on individual order lines.

This module adds a 'Split Delivery' option to Sale Order lines, enabling the creation of separate delivery orders for selected products.

Compatibility

  • Tested with Odoo 18.0
